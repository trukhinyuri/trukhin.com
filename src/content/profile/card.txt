Outside my day job
I founded TRUKHIN #CloudRING, an open-source cloud platform for independent and sovereign cloud providers, and I'm its lead maintainer. At its core is OCSv3 — the third generation of the Open Cloud Standard I originated in production — an open contract between a provider's platform and the services it offers, with hexagonal provider ports and zero-dependency Go and Rust SDKs designed so that a service built once runs at any provider that adopts it. I build it in the open as an AI-native software factory: coordinated fleets of AI agents write, review and test the code under my architectural direction, I decide what merges, and a goal counts as done only when verified on a live deployment. Releases carry Sigstore-signed SLSA Build Level 3 provenance and CycloneDX SBOMs, and every release bundle is built twice from source to match byte for byte before attestation.
